# Portfólio — Davi Bento

Currículo online feito para a Atividade Prática da disciplina Fundamentos da Programação Web (Uninter).

**Site:** https://benditodavi.github.io/portfolio-davi-bento/

## Tecnologias

HTML5, CSS3 e JavaScript puros, sem frameworks nem bibliotecas.

## Estrutura

- `index.html`: página única com as seções Sobre mim, Formação, Portfólio e Contato
- `css/estilo.css`: visual e responsividade
- `js/script.js`: validação e simulação de envio do formulário de contato
- `imagens/`: imagens do site
